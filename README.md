# FundamentalsOfML

## Implemented Algorithms

- Linear Regression
- Logistic Regression
- KNN
- Decision Trees / BDT
- Vanilla Neural Networks
- PyTorch Models
- Gradient Descent & Decision Boundary Visualizations
